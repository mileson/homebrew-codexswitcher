CodexSwitcher 的 Homebrew 配方仓库，用于通过 Homebrew 安装和维护命令行工具。

<a id="readme-detail-features"></a>

## ✨ 核心特性

- **配方位置明确。** Formula 保存 CodexSwitcher 的 Homebrew 安装定义。
- **来源与版本可查。** 维护时从配方核对软件来源、版本与校验信息。

<a id="readme-detail-audience"></a>

## ✅ 适用场景

适合使用或维护 CodexSwitcher Homebrew 配方的读者。

## 🚀 快速开始

配方位于 [`Formula/cjfcodexswitcher.rb`](Formula/cjfcodexswitcher.rb)。安装前可先阅读配方中的下载地址、校验值和版本信息。

使用方式与工具说明见 [CodexSwitcher 主仓库](https://github.com/mileson/CodexSwitcher)。
